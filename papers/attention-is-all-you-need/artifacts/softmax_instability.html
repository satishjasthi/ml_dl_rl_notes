Unscaled versus divided by √dₖ

The orange path uses softmax(q·k); the green path uses softmax(q·k / √dₖ).

no √dₖ scaling: saturates toward one winner with √dₖ scaling: keeps alternatives alive
Press play to increase dₖ from 1 to 1024. Both curves use stable exponentiation so the plot isolates the sharpness problem.
What “unstable” means here: as dₖ grows, unscaled dot products become larger. Softmax magnifies their differences until one key gets almost all the probability. At sufficiently extreme values, a naïve exp(score) can also overflow. Dividing by √dₖ controls the score scale; subtracting the maximum logit makes the exponential calculation numerically safe.

The plot uses max-shifted softmax for both curves to separate two ideas: √dₖ prevents attention from becoming too sharp, while max subtraction prevents floating-point overflow.
