# ViT questionnaire answer key

These are model answers, not the only acceptable answers. Strong answers should state assumptions and distinguish paper evidence from extrapolation.

## Stage 1 — Conceptual understanding

1. **Core move:** ViT splits an image into patches, treats patches as tokens, and sends the sequence through a standard Transformer encoder. It removes most CNN-specific locality and translation-equivariance assumptions; those relationships must be learned from data.
2. **Token count:** $224/16=14$ patches per side, so $14^2=196$ patch tokens. With one class token, the Transformer sees $197$ tokens.
3. **Projection:** Raw flattened patches have dimension $P^2C$, which depends on patch size and channels. The learned projection maps them into the common hidden width $D$ expected by every Transformer layer and learns a useful feature basis.
4. **No position embeddings:** The model loses explicit information about where tokens came from. Self-attention is content-based and does not automatically know the 2-D arrangement, so spatially permuted patch sequences can become difficult to distinguish.
5. **Class token:** It is a learned readout slot that attends to patch tokens and aggregates image-level information. It is not a physical region or a fixed crop.
6. **Small-data weakness:** CNNs provide useful visual priors for free. ViT has to learn locality, edges, and spatial regularities from examples, so it generally benefits more from large-scale pretraining.
7. **Patch size 16 to 8:** The number of patches per side doubles and the token count becomes four times larger. The attention score matrix grows about sixteen times in its token-token area, while small details are represented more precisely. Exact cost also depends on the implementation and other layers.
8. **Claim distinction:** The paper shows that CNN reliance is not necessary in a large-scale pretraining regime. It does not show that convolution is useless; CNNs can be more data-efficient, cheaper, or better suited to local/high-resolution tasks.

## Stage 2 — Application-level questions

9. **Satellite pipeline:** $256/16=16$ patches per side, giving $256$ patch tokens and $257$ tokens with the class token. Attention has a $257 \times 257$ interaction matrix per head and must store activations for backpropagation. High-resolution batches, multiple heads, and feature width can make memory the bottleneck.
10. **Resolution change:** The number of patch positions changes from $14 \times 14$ to $24 \times 24$. Reshape the learned 1-D spatial portion into its 2-D grid, interpolate it to $24 \times 24$, flatten it again, and keep the class-token embedding unchanged. Validate interpolation because it is a transfer heuristic, not a guarantee.
11. **Strategy:** Start with large-scale self-supervised or supervised pretraining on the unlabeled/domain-relevant collection, then fine-tune with labels. A CNN or hybrid is a sensible default if the collection is small or the domain is strongly local; a pure ViT is more attractive if pretraining scale and compute are sufficient. The paper motivates this conditional choice.
12. **Responses:** (a) use gradient accumulation or smaller batches; (b) use activation/mixed-precision memory optimizations; (c) choose an intermediate patch size or a smaller model; (d) use local/sparse attention; (e) train a hierarchical or hybrid model. Each trades detail, global context, throughput, implementation complexity, or accuracy.
13. **Tiny objects:** Decrease patch size or use a multi-scale/hierarchical design so the object is not averaged into one coarse token. Then address the increased sequence cost with windows, feature pyramids, cropping, or sparse attention. Labels, resolution, augmentation, and class imbalance may dominate the result.
14. **Attention interpretation:** Test across examples, heads, layers, random seeds, and classes; compare with segmentation/box annotations or controlled perturbations; measure whether removing highlighted regions changes predictions; and compare with gradient- or perturbation-based methods. A visually appealing map alone does not establish causal explanation.
15. **Shapes:** There are $(32/4)^2=64$ patch tokens and $65$ tokens after the class token. Patch dimension is $4^2 \cdot 3=48$. Patchified input: $(8,64,48)$; embedded tokens before the encoder: $(8,65,64)$; encoder output: $(8,65,64)$; class-token readout: $(8,64)$; logits for $K$ classes: $(8,K)$.
16. **Debug order:** Verify labels and class balance; assert patch/token shapes and image normalization; overfit a tiny batch; inspect logits and loss; check learning rate, initialization, and gradient norms; compare with and without positional embeddings; test larger pretraining or stronger augmentation; only then conclude the task needs stronger inductive bias. This order isolates simple failures before architectural conclusions.

## Stage 3 — Scenario-level complex questions

17. **$1024 \times 1024$ deployment:** Larger patches reduce $N$ and latency but can erase small objects; test recall by object size. Window attention limits quadratic cost but needs cross-window communication; test long-range classes and shifted/window-connection variants. Hierarchical/hybrid encoders improve multi-scale locality and efficiency but add design complexity and may change transfer behavior. Benchmark latency, memory, throughput, and accuracy on a representative resolution mix.
18. **Two simultaneous shifts:** Separate resolution effects from sensor/domain effects using controlled resampling and sensor-matched subsets. Inspect normalization statistics, patch distribution, positional interpolation, label semantics, and calibration. Adapt in stages: validate preprocessing, interpolate or reinitialize position embeddings carefully, use domain-relevant unlabeled pretraining or parameter-efficient adaptation, then fine-tune with robust validation and ablations.
19. **Fair matrix:** Cross at least two data scales, two model sizes, two patch sizes, pretrained versus scratch, matched training compute, and the same augmentation/optimization family. Report parameter count, tokens per image, training FLOPs/time, peak memory, and transfer protocol. Include CNN, pure ViT, and hybrid baselines, with multiple seeds and confidence intervals. A claim without matched compute and data is underdetermined.
20. **Medical task:** Prefer a CNN or hybrid/multi-scale model initially because labels are scarce, lesions are small, and local texture matters. Use domain-specific self-supervised pretraining, careful augmentation, class-imbalance handling, and lesion-size-stratified evaluation. A pure ViT becomes attractive if there is substantial unlabeled medical data, enough resolution/compute, and evidence that global context improves the clinical task; validate sensitivity and calibration, not only accuracy.
21. **Wide-image drop:** Inspect the original and interpolated grid shapes, aspect-ratio assumptions, ordering of position embeddings, class-token handling, preprocessing resize/crop policy, and whether the model saw non-square layouts during adaptation. Reproduce with square and wide controls, compare bicubic interpolation with 2-D relative or factorized position schemes, and fine-tune on representative wide images. Do not assume the failure is attention itself.
22. **Explanation risk:** Attention weights describe one information-routing quantity and can be changed without changing predictions; they are not automatically faithful causal explanations. Evaluate deletion/insertion, pointing or localization metrics where labels exist, counterfactual patch perturbations, stability across seeds, and agreement with independent attribution methods. State clearly whether the result is a visualization, faithfulness test, or human-facing explanation.
23. **Budget framework:** First match the deployment constraint and estimate token cost. Compare marginal validation gains per unit compute for more pretraining data, model width/depth, smaller patches, and training duration using a small pilot or scaling sweep. Prioritize data diversity and pretraining when the model is data-limited, model scale when under-capacity is evident, smaller patches when detail is the bottleneck, and longer training only when learning curves show undertraining. The paper supports a scaling interaction, not a universal ranking.
24. **Ablation:** Hold dataset, augmentation, optimizer, training steps, and evaluation fixed. Compare (a) local/no-attention or restricted attention versus global attention; (b) same parameter count with different patch sizes; (c) same token count but matched parameter count; (d) pretrained versus scratch; and (e) compute-matched CNN/hybrid baselines. Record accuracy by object scale, calibration, FLOPs, memory, and throughput. Only a controlled matrix can separate global-context, token-count, parameter, and pretraining effects.
